# Versions

- Raise a plugin's patch for a change that leaves how its user works as it was: a fix, a wording, a tighter or checked step, a model or effort setting.
- Raise its minor for a change in what its user can do or how the work runs: a new skill, command, agent or workflow, a new stage, or a visible change in the decisions or output the user meets.
- Keep the major at 0 until the owner names 1.0.
