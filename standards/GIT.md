# Git

## GIT-1. Search the open issues for the same subject before opening one.

## GIT-2. Name a scope after an area of the project, not after a file.

## GIT-3. Report a vulnerability through the channel SECURITY.md names, never in a public issue.

## GIT-4. Read the history of pull requests with `git log --first-parent`, and the reason for a line with `git blame` and `git show`.

## GIT-5. When a secret reaches a commit, an issue or a pull request, stop and tell the person, who revokes it; never rewrite history to hide it.

## GIT-6. On the server, protect the default branch against force pushes, deletion and pushes without a pull request, with no bypass; allow merge commits with the pull request's title and description as the message, and delete head branches after merge.
