# Markdown

## MD-1. Write no sentence about the file itself.

## MD-2. Use no word of praise or degree, such as `fast`, `simple` or `robust`, that a measurement does not back; a word that classifies, such as `external` or `public`, is not one.

## MD-3. Put a phrase in a table cell, never a sentence.
