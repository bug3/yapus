# Markdown

## MD-1. Write every rule as one heading, its id and one sentence, with nothing under it.

## MD-2. Write no sentence about the file itself.

## MD-3. Use no adjective of degree that a measurement does not back.

## MD-4. Put a phrase in a table cell, never a sentence.

## MD-5. Open no list with one item and no section with one subsection.

## MD-7. State where a rule applies when it does not apply everywhere.

## MD-8. Leave no two rules that cannot both be obeyed, in one file or across files.
