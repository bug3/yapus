# Terms

## TERM-1. Call the human who speaks in the session the person.

## TERM-2. Call any other human a human.

## TERM-3. Call an AI that acts an agent when the sentence holds for every one of them.

## TERM-4. Call the agent the person speaks with the main agent.

## TERM-5. Call an agent that another agent or a workflow launched a subagent, and the one that launched it its launcher.

## TERM-6. Call a subagent that a workflow launched a workflow agent, and name one by its stage.

## TERM-7. Call the file that defines a subagent an agent definition, and the name a launch gives an agent type.

## TERM-8. Call the place where the person and the main agent work the session; never write the session as the one that acts.

## TERM-9. Write you for the reader of the text, whoever that is.
